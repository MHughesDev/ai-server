# Glossary (canonical terms)

| Term | Meaning |
|------|---------|
| Ingress | Deterministic request boundary (auth, limits, validation) before Brain Stem. |
| Brain Stem | First cognitive step: canonicalize + intent. |
| Orchestrator | Policy, budgets, routing, dispatch gate; owns loops and nesting. |
| Workflow | Versioned graph of engine steps (`workflow_id`, `PipelinePlan.pipeline_type`). |
| Gateway | Model, tool, or memory choke point. |
| WANT-xxx | Target requirement ID in `Target-State-Backlog.md`. |
