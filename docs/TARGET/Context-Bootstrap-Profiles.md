## Profile A — minimal (low tokens)

1. `AGENTS.md`  
2. `docs/CURRENT/As-Built-Snapshot.md` (once filled)  
3. The single file for your task (e.g. `docs/SPEC/02_API_Contracts.md`)

Add `docs/REFERENCE/World-Model-Codebase.md` + relevant SPEC sections.

## Profile C — production readiness

Add `docs/OPERATIONS/Production-Readiness-Go-No-Go-Summary.md` + `docs/OPERATIONS/Production-Readiness-Gaps-Report.md`.

## Profile D — target vs current

Add `docs/TARGET/Target-State-Backlog.md` (reference by WANT ID; avoid loading entire file if possible).
